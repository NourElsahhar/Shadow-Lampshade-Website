# Project Structure

## app

Contains the application's routes, layouts, pages, metadata, and global configuration.

## components

Contains reusable UI components that can be shared across different pages and sections.

## sections

Contains complete page sections that combine multiple components into a single feature.

## hooks

Contains reusable custom React hooks to share application logic.

## lib

Contains reusable libraries, services, and external integrations.

## constants

Contains application constants such as colors, routes, and configuration values.

## data

Contains static data used throughout the application.

## types

Contains shared TypeScript types and interfaces.

## styles

Contains global styles and reusable styling utilities.

## utils

Contains helper and utility functions used across the project.
